# Guía de Instalación y Ejecución del Proyecto (SLEP)

Este documento contiene los pasos exactos y las dependencias necesarias para levantar el proyecto en un entorno local. El sistema está dividido en dos partes: el Backend (Python/FastAPI) y el Frontend (React/Node.js).

---

## 1. Configuración de la Base de Datos (PostgreSQL)
Antes de levantar el proyecto, debes tener tu servidor de base de datos corriendo.
1. Crea una base de datos local en PostgreSQL llamada `sistema_matriculas_sleep` (o el nombre acordado).
2. Revisa el archivo `main.py` en el backend y asegúrate de que las credenciales en la función `get_db_connection()` coincidan con tu usuario y contraseña local de Postgres (por defecto suele ser usuario `postgres` y tu contraseña personal).

---

## 2. Instalación del Backend (Python)

El servidor y la API están construidos con FastAPI. Sigue estos pasos en tu terminal, dentro de la carpeta del backend:

1. Crea el archivo `requirements.txt` en la raíz de la carpeta del backend con este contenido:
fastapi==0.110.0
uvicorn==0.28.0
psycopg2-binary==2.9.9
reportlab==4.1.0
python-multipart==0.0.9

2. Instala todas las dependencias de golpe ejecutando:
pip install -r requirements.txt

**¿Qué hace cada librería instalada?**
* fastapi: Framework principal para construir la API.
* uvicorn: Servidor web que levanta la aplicación.
* psycopg2-binary: Conector para que Python pueda hablar con PostgreSQL.
* reportlab: Librería para generar los certificados PDF en memoria.
* python-multipart: Herramienta para procesar subida de archivos (necesaria para la carga masiva de CSV).

3. Levanta el servidor del backend con:
python -m uvicorn main:app --reload
(El servidor quedará corriendo en http://127.0.0.1:8000)

---

## 3. Instalación del Frontend (React)

La interfaz está construida con React y empaquetada con Vite. Sigue estos pasos abriendo una *nueva* pestaña en tu terminal, dentro de la carpeta del frontend:

1. Instala todas las dependencias definidas en el proyecto ejecutando:
npm install

**¿Qué librerías principales se instalarán automáticamente según el package.json?**
* react / react-dom: El núcleo de la interfaz de usuario.
* react-router-dom: Para manejar la navegación entre pantallas (Directorio, Matrículas, etc.).
* lucide-react: La colección de iconos que usamos en los botones.
* tailwindcss: El framework de estilos y diseño.
* vite: El empaquetador que compila el código a alta velocidad.

2. Levanta la interfaz gráfica ejecutando:
npm run dev
(La terminal te entregará un enlace, generalmente http://localhost:5173, al que debes entrar desde tu navegador).

---
¡Listo! Si seguiste estos pasos, deberías tener la API conectada a tu base de datos y la pantalla de React funcionando perfectamente.
